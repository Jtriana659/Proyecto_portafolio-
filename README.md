# 🚀 Mi Portafolio Web Personal

Este repositorio contiene el código fuente de un portafolio web personal, diseñado para mostrar  habilidades, proyectos y proporcionar una vía de contacto profesional. Es un proyecto ligero y 100% *responsive*, implementado con tecnologías web fundamentales.

## 🌟 Características Principales

* **Navegación Fluida:** Desplazamiento suave (Smooth Scroll) entre secciones (`Sobre mí`, `Habilidades`, `Proyectos`, `Contacto`).
* **Diseño Adaptable (Responsive):** Menú de navegación móvil con ícono de hamburguesa (`☰`) que se adapta a cualquier tamaño de pantalla (gracias a media queries en `styles.css`).
* **Filtro de Proyectos:** Funcionalidad dinámica para filtrar proyectos por categoría (`Web` o `Móvil`) usando JavaScript.
* **Modal de Imágenes:** Al hacer clic en la imagen de un proyecto, se abre una vista modal para una visualización ampliada.
* **Validación de Formulario:** Formulario de contacto con validación en tiempo real (al escribir) y validación final al intentar enviar.
    * Verifica campos obligatorios (`Nombre`, `Mensaje`).
    * Valida el formato de correo electrónico (`Email`).

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando únicamente el *stack* básico de desarrollo web:

* **HTML5:** Estructura semántica del portafolio.
* **CSS3:** Estilos básicos, diseño responsivo y presentación.
* **JavaScript (Vainilla):** Implementación de toda la interactividad (navegación, filtros, modal y validación).

## 📂 Estructura del Proyecto

El repositorio está organizado de la siguiente manera:
. ├── index.html # Estructura principal de la web. ├── styles.css # Todos los estilos y media queries para el diseño responsivo. └── scripts.js # Lógica del frontend (menú, scroll, filtros, validación).

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/Jtriana659/Proyecto_portafolio-.git](https://github.com/Jtriana659/Proyecto_portafolio-.git)
    ```
2.  **Navegar a la carpeta:**
    ```bash
    cd Proyecto_portafolio-
    ```
3.  **Abrir el proyecto:**
    * Simplemente abre el archivo `index.html` en tu navegador web preferido. No se necesita un servidor local.
